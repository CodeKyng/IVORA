# oriel-studio-template — source code

Live demo: https://kedhar-components.pages.dev/#oriel-studio-template

Folders under components/ are React + TypeScript + Tailwind components.
Main file: components/oriel-studio-template/oriel-studio-template.tsx  (usage example: components/oriel-studio-template/demo.tsx)

Put each folder's .tsx file at src/components/ui/<folder>.tsx in a
shadcn-style project (the code imports siblings as @/components/ui/<name>).

npm packages used: gsap, react, three
